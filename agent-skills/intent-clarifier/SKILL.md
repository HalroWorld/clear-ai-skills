# 요청 의도 정리하기

사용자의 말을 임의로 바꾸거나 범위를 넓히지 않고, AI가 바로 이해하고 실행할 수 있는 요청으로 정리한다.

## 정리 순서

1. 사용자가 이루려는 목적을 한 문장으로 추린다.
2. 요청에 포함된 대상, 범위, 제약, 원하는 결과물을 구분한다.
3. 중복·감탄·배경 설명은 줄이고, 의미를 바꾸는 조건은 남긴다.
4. 모호한 부분은 추측해 채우지 말고 `확인이 필요한 점`으로 분리한다.
5. 실행 가능한 최종 요청을 짧게 제시한다.

## 출력 형식

```text
목적: [사용자가 하려는 일]
조건: [반드시 지켜야 할 조건]
결과물: [원하는 결과]

정리된 요청:
[AI에게 그대로 전달할 한 단락 또는 짧은 목록]

확인이 필요한 점:
- [없으면 이 항목을 생략]
```

사용자가 단순히 문장만 다듬어 달라고 했다면 목적·조건 표를 생략하고 다듬은 문장만 제공한다. 사용자의 결정을 대신하거나, 확인되지 않은 요구사항을 추가하지 않는다.

## 예시

입력: “우리 앱 로그인 좀 고쳐줘. 요즘 가끔 풀리고 사람들도 불편하대. 보안은 유지하면서 빨라졌으면 좋겠어.”

정리된 요청: “앱 로그인 세션이 간헐적으로 만료되는 원인을 조사하고 수정해 주세요. 기존 인증 보안 수준은 유지하면서 재로그인 횟수와 로그인 지연 시간을 줄여 주세요. 원인, 변경 내용, 테스트 결과를 함께 설명해 주세요.”
