# 스킬 목표

사용자가 전문 용어를 몰라도 편하게 질문할 수 있게 하고, AI가 질문의 의도를 파악해 쉬운 말로 핵심만 답하도록 돕습니다. 답변은 짧게 쓰되 결론과 중요한 조건은 남깁니다. 질문을 잘 다듬지 못했거나 기술적인 표현을 몰라도 자연스럽게 이해하고 답하는 것이 핵심입니다.

이 프로젝트의 이름은 폴더 구조를 설명하는 `agent-skills`보다, 사용자가 쉽게 묻고 이해하기 쉬운 답을 얻는 경험을 직접 보여주는 이름을 우선합니다.

# 쉽게 묻고 쉽게 답하기

AI의 길고 기술적인 답변을 읽고, 현재 상황과 다음 행동을 쉽게 이해하도록 돕는 한국어 스킬입니다.

## 하는 일

- 핵심 결론을 먼저 전달합니다.
- 기술적인 작업 보고를 완료한 일, 남은 일, 결정할 일로 정리합니다.
- 중요한 조건과 불확실성, 정확히 입력해야 하는 명령어는 보존합니다.
- 원문에 없는 사실이나 추천 근거를 만들지 않습니다.

## Codex에서 설치

이 저장소를 내려받아 `SKILL.md`와 `agents` 폴더가 들어 있는 디렉터리를 개인 스킬 폴더의 `simple-explanation`에 복사하세요. 기본 위치는 `~/.codex/skills/simple-explanation/`입니다. 기존에 같은 이름의 스킬이 있다면 먼저 백업하세요.

새 대화에서 다음과 같이 호출하세요.

```text
$simple-explanation 아래 내용을 쉽게 풀어줘.

[작업 보고 붙여넣기]
```

## 다른 AI에서 사용

`SKILL.md`의 본문을 지침으로 제공하고 정리할 내용을 전달하세요. 스킬 설치 방식과 자동 호출 지원 여부는 사용하는 도구에 따라 다릅니다. 모든 모델에서 동일한 결과를 보장하지 않습니다.

## 예시

원문:

> 요청 중복 처리 방지 로직을 추가했고 자동화 테스트는 통과했습니다. 실환경 재전송 시나리오는 미검증입니다.

정리:

> 같은 요청이 두 번 처리되지 않도록 수정했고, 자동 검사도 통과했습니다. 실제 서비스에서 요청이 다시 전송될 때도 제대로 막히는지는 아직 확인하지 않았습니다.
